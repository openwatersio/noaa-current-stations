# NOAA Current Stations

This dependency-free Node 20+ package extracts NOAA CO-OPS current-station bundles.

```bash
git clone https://github.com/openwatersio/noaa-current-stations.git
cd noaa-current-stations
npm install
npm test
```

Run `npm run validate:bundle` after changing bundle code or data. `currents.json` is
committed for review but intentionally excluded from the npm package.
